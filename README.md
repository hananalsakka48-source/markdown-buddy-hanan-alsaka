# Synthetic Student Scores Analysis

## Overview

This project uses synthetic student scores to demonstrate basic data analysis in R, including calculating the mean, maximum, and minimum scores.

## Project Files

- student_scores.R: An R script that analyzes synthetic student scores.

## Requirements

- R (version 4.6.1)

## Installation

Install R and RStudio on your computer to run this project. No additional R packages are required.

## Example Usage

Open the project in RStudio and run the student_scores.R script to display the scores and calculate the mean, maximum, and minimum values.
